Spanish voice assistant for the Waveshare ESP32-S3-Touch-AMOLED-1.75.

⚠️ Preview: early version.
After installing, the board asks you to pick your Wi-Fi on its own screen. "Hola Bug" and spoken answers (time and date) need the Bug server running on your PC; set its address in Settings. Touch, swipes, Settings and Wi-Fi setup work. Email, calendar and Claude answers are still being built.

⚠️ Use desktop Chrome or Edge. This browser does not support Web Serial.

Install

Connect the board by USB, press install and select its serial port.

Browser not supported (use Chrome/Edge). Needs HTTPS or localhost.

Coming from another firmware? Installing Bug replaces whatever is on the board. Turn on Erase device for a clean start. This also deletes any saved data from the old firmware, so back it up first.

Set up the board

Do this after installing. Fill in what you want; leave the rest empty. When you press the button the page sends it to the board over the USB cable and the board keeps it in its own memory, so it works away from your computer too.

How to get the app password / use another mail provider

Gmail: turn on 2-step verification, then open myaccount.google.com/apppasswords, create one called "Bug" and paste the 16 letters here. It is not your normal password and it only gives access to mail. Another provider: write its IMAP server below (for example outlook.office365.com).

Pick the board's port when asked, and close any other tab or program using it first. Only 2.4 GHz networks work (the board has no 5 GHz radio). What you type stays in this page and goes only to the board: nothing is uploaded. The board keeps the passwords in its own memory; anyone holding the board and a USB cable could read them back, so use an app password, never your main one.
