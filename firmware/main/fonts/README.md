# Fonts

`Montserrat-Medium.ttf` is Montserrat by Julieta Ulanovsky and others, licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org). It is the same
file LVGL ships for its built-in fonts. The firmware embeds it and draws it with
LVGL's TinyTTF renderer so the screen can show Spanish letters (á é í ó ú ü ñ ¿ ¡),
which LVGL's pre-built fonts don't include.
