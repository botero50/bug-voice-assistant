BOOK READER
───────────
• Complexity: ⭐⭐ MEDIUM (3 hours)
• Offline: ✅ YES
• Formats: TXT, EPUB, Markdown
• Technology: File parser + TTS pipeline
• Storage: Scalable (user books)
• Features: Chapter detection, bookmarks, progress tracking

STORY TELLER
────────────
• Complexity: ⭐⭐ MEDIUM (2 hours)
• Offline: ⚠️ HYBRID
• Technology: Claude API or local TinyLLaMA
• Genres: Adventure, children, mystery, fable
• Caching: Pre-load 100 stories offline
• APIs: Claude API (optional)

ONLINE RADIO
────────────
• Complexity: ⭐⭐ MEDIUM (2 hours)
• Offline: ⚠️ HYBRID
• API: Radio Browser (62,453 stations, free, no key)
• Streaming: HTTP audio to ESP32 speaker
• Cache: 50 popular stations for offline
• Features: Search by country/language, fallback

CRYPTO PRICES
─────────────
• Complexity: ⭐ LOW (2 hours)
• Offline: ⚠️ HYBRID
• APIs: CoinGecko (10K/month free), Coinpaprika (1K/day)
• Caching: 5-minute TTL
• Storage: <10 KB
• Features: Multiple cryptos, voice announcements

SCREEN GAMES
────────────
• Complexity: ⭐⭐⭐ HARD (3 hours)
• Offline: ✅ YES
• Technology: C/ESP-IDF, game engine
• Display: AMOLED 466×466 touchscreen
• Games: Snake, Tetris, 2048, Flappy Bird, Breakout, Space Invaders
• Storage: ~100 KB (all games)
• Performance: 60 FPS target

VOICE GAMES
───────────
• Complexity: ⭐⭐ MEDIUM (3 hours)
• Offline: ✅ YES
• Technology: Flask service + LLM/logic
• Games: Trivia, Akinator, Riddles, Word Association, etc.
• Storage: <200 KB (question databases)
• Interactions: Pure voice, no screen needed

HYBRID GAMES
────────────
• Complexity: ⭐⭐ MEDIUM (2 hours)
• Offline: ✅ YES
• Technology: C + Flask + voice command parsing
• Features: Voice commands for screen games
• Feedback: Voice announcements of game events
• Examples: "Move left" for Snake, "Rotate" for Tetris
