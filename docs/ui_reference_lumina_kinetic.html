Hardware & Firmware Implementation Notes

Display Parameters

• Display IC: ST7701S / NV3041A (3-wire SPI + 18-bit RGB interface)
• Resolution: 480×480 Circular (Active Radius = 240px)
• Touch Controller: CST816S I2C capacitive multi-touch

LVGL v9 / LovyanGFX Vector Primitives

The kinetic diaphragm consists of 16 radial pill droplets. Instead of costly framebuffers or blur filters, each petal is calculated with polar coordinates and drawn using LovyanGFX: 

// LovyanGFX DMA Sprite rendering (16 Petals)
float step = (2.0f * PI) / 16;
for(int i = 0; i < 16; i++) {
  float theta = i * step + rotation;
  float r_inner = 90.0f + audio_envelope * 25.0f;
  float r_outer = r_inner + 18.0f + petal_stretch[i];
  lcd.fillSmoothCircle(cx + cos(theta)*r_outer, cy + sin(theta)*r_outer, 5, color);
}
Microphone & Audio I2S Routing

Onboard dual I2S MEMS microphones (MSM261S4030H0R) sample 16kHz audio directly to an ESP32 DMA buffer, feeding a fast 32-point integer FFT to drive the radial petal amplitudes.
