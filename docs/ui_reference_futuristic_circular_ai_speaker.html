[ESP32-S3] LovyanGFX Lightweight Implementation

Direct line/arc vector rendering • 60+ FPS on ESP32-S3 PSRAM

Unlike heavy canvas shaders, this design uses pure Bresenham arcs, discrete angle steps, and tick-marks. Here is the minimal LovyanGFX C++ routine to draw the Cobot Servo telemetry directly onto ST7701S: 

// Waveshare ESP32-S3 Round LCD 480x480
#include <LovyanGFX.hpp>

static LGFX lcd;
static LGFX_Sprite canvas(&lcd); // 480x480 8-bit or 16-bit DMA sprite

void drawCobotTelemetry(float audioAmp, float jointAngle) {
  canvas.fillScreen(TFT_BLACK);
  const int cx = 240, cy = 240;

  // 1. Outer Encoder Tick Marks (No trigonometry in loop, precomputed steps)
  for (int i = 0; i < 48; i++) {
    float rad = i * (6.283185f / 48.0f);
    int len = (i % 4 == 0) ? 10 : 4;
    int x1 = cx + cosf(rad) * (230 - len);
    int y1 = cy + sinf(rad) * (230 - len);
    int x2 = cx + cosf(rad) * 230;
    int y2 = cy + sinf(rad) * 230;
    canvas.drawLine(x1, y1, x2, y2, (i % 4 == 0) ? TFT_ORANGE : 0x3186);
  }

  // 2. Active Servo Audio Arc (Reactive to I2S mic)
  int arcSpan = (int)(audioAmp * 120.0f);
  canvas.drawArc(cx, cy, 185, 180, 270 - arcSpan, 270 + arcSpan, TFT_YELLOW);

  // 3. Center Gimbal Crosshair
  canvas.drawCircle(cx, cy, 40, 0x52AA);
  canvas.drawFastHLine(cx - 50, cy, 100, TFT_ORANGE);
  canvas.drawFastVLine(cx, cy - 50, 100, TFT_ORANGE);

  // 4. Push directly via DMA to round screen
  canvas.pushSprite(0, 0);
}
